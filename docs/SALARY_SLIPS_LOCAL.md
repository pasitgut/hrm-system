# เงินเดือนบน Local

หน้าทำเงินเดือนอยู่ที่ `/payroll` และคำนวณจากโปรไฟล์พนักงานกับคำขอ OT ที่อนุมัติในระบบ ไม่ต้องนำเข้าไฟล์ Excel เพื่อสร้างรายงานเงินเดือน

การติดตั้งใช้ PostgreSQL และบัญชี HRM ตามขั้นตอนปกติ ผู้ใช้ต้องมีสิทธิ์ `salary_slips.view` และ `employees.compensation.view` เพื่อดูข้อมูล และ `salary_slips.export` เพื่อดาวน์โหลด Excel

ขอบเขตแหล่งข้อมูล สูตร OT รอบ 26–25 และรายการที่ยังไม่คำนวณอัตโนมัติ ดูที่ [PAYROLL_DATA.md](PAYROLL_DATA.md)

ข้อมูลสลิปและประวัติที่นำเข้าก่อนหน้านี้ยังอยู่ในฐานข้อมูลเพื่อเก็บรักษาประวัติ แต่หน้ารายการและหน้านำเข้าเดิมจะพากลับไป `/payroll` และไม่ได้ใช้เป็นแหล่งคำนวณ payroll ใหม่

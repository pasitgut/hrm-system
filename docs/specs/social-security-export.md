# Spec: ส่งออกรายงานประกันสังคม (สปส. 1-10)

สถานะที่สำรวจ: **ลบ route เก่า (`app/api/payroll/social-security/export/route.ts`) ออกแล้ว** เนื่องจากไม่มี UI เรียกใช้และคิวรีจากตาราง `salary_slips` เดิมที่ถูกลบหลังระบบสลิปเปลี่ยนเป็นแบบ stateless (`commit 5bb77cc`, เก็บกวาดใน `drizzle/0026_clean_legacy_schema.sql`) — รอการตัดสินใจแหล่งข้อมูลใหม่ก่อนสร้าง API และ UI ของ สปส. 1-10 ใหม่ให้ตรงสถาปัตยกรรมปัจจุบัน

## เป้าหมาย

ให้ผู้มีสิทธิ์ด้านเงินเดือนสามารถส่งออกไฟล์ Excel แบบ สปส. 1-10 ได้จากหน้า `/payroll` โดยใช้แหล่งข้อมูลที่ตรงกับกระบวนการคำนวณเงินเดือนปัจจุบัน

## ขั้นตอน prerequisite

1. เจ้าของผลิตภัณฑ์/ฝ่ายบัญชี ยืนยันแหล่งข้อมูลต้นทาง (source of truth) ของค่าจ้างและเงินสมทบประกันสังคมสำหรับ สปส. 1-10 ว่าจะใช้แนวทางใด:
   - **ทางเลือก A:** คำนวณจากข้อมูลเงินเดือนภายในระบบ (`/api/payroll` + รายการหักประกันสังคมในโปรไฟล์พนักงาน)
   - **ทางเลือก B:** อัปโหลดไฟล์ Excel เงินเดือนแบบ stateless (แบบเดียวกับการออกสลิป PDF/XLSX ใน `/payroll`) แล้วสร้างไฟล์ สปส. 1-10 ทันที
   - **ทางเลือก C:** ยกเลิกฟีเจอร์นี้หากฝ่ายบัญชีส่งออกจากระบบบัญชีภายนอกอยู่แล้ว
2. ยืนยันเกณฑ์เพดานค่าจ้าง, อัตราเงินสมทบ, พนักงานที่ได้รับยกเว้น/ยังไม่ขึ้นทะเบียน และกรณีพนักงานไม่มีเลขบัตรประชาชน

## ข้อกำหนด (หลังยืนยันแนวทาง)

- เพิ่มส่วนควบคุมการส่งออก สปส. 1-10 ในหน้า `/payroll` (`components/hrm/payroll/PayrollModule.jsx`) รองรับ:
  - เลือกงวด (เดือน/ปี), ขอบเขต (ตามแผนก / รายบุคคล), การเรียงลำดับ (`code`, `name`, `department`) และประเภทยื่น (`normal` / `additional`)
  - แสดงข้อความแจ้งเตือนชัดเจนกรณีพนักงานยังไม่มีเลขบัตรประชาชน หรือไม่มีข้อมูลค่าจ้าง/เงินสมทบ
- สร้าง `app/api/payroll/social-security/export/route.ts` ใหม่โดยดึงข้อมูลจาก source of truth ที่ยืนยันแล้ว (ไม่พึ่งตาราง `salary_slips` เดิม)
- ตรวจสิทธิ์ฝั่ง server ด้วย `salary_slips.view` + `salary_slips.export` (และ `employees.compensation.view` ตามโครงสร้างสิทธิ์ปัจจุบันของ `/payroll`) และตอบกลับพร้อม header `Cache-Control: no-store`
- คอลัมน์ในไฟล์ Excel ตรงตามรูปแบบ สปส. 1-10 (เลขบัตรประชาชน format text `@`, คำนำหน้า, ชื่อ, สกุล, ค่าจ้าง, เงินสมทบ format `#,##0.00`)

## เกณฑ์ตรวจรับ

- มีข้อสรุปแหล่งข้อมูลและกติกาค่าจ้าง/เงินสมทบก่อนเริ่มแก้โค้ด
- ผู้มีสิทธิ์สามารถส่งออกไฟล์ `.xlsx` สปส. 1-10 ได้จากหน้า `/payroll` และยอดตรงกับแหล่งข้อมูลต้นทาง
- กรณีขาดเลขบัตรประชาชนหรือข้อมูลไม่ครบ ระบบแจ้งรายชื่อ/รหัสพนักงานที่ต้องแก้ไขชัดเจน
- API ปฏิเสธผู้ไม่มีสิทธิ์ (`401`/`403`) และมี automated tests ครอบคลุมกรณีปกติ, ข้อมูลไม่ครบ, และสิทธิ์ไม่พอ
